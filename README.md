# RouteForge — Intelligent Vehicle Route Optimization Platform

> A logistics and vehicle route optimization platform for managing delivery dispatches, vehicle assignments, geographic constraints, and optimized delivery routes.

RouteForge helps logistics operations assign delivery jobs to vehicles and generate optimized delivery routes using **GraphHopper** for geographic routing and **Jsprit** for Vehicle Routing Problem (VRP) optimization.
